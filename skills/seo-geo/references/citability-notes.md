# GEO citability notes

Use these as editorial checks, not as promises about model behavior.

## Make answers self-contained

- Put the short answer near the start of a section.
- Name the subject explicitly instead of relying on pronouns or page context.
- Define specialist terms before using them.
- Keep dates, versions, jurisdictions, units, and conditions attached to claims.

## Make evidence inspectable

- Link or name the source for consequential claims when one is available.
- Distinguish measured facts, reported claims, expert interpretation, and recommendations.
- Preserve uncertainty and disagreement instead of flattening it into certainty.
- Include the source date and scope when freshness affects meaning.

## Make structure useful

- Use descriptive headings that correspond to real questions.
- Use lists, tables, examples, and definitions when they reduce ambiguity.
- Avoid keyword stuffing, repetitive conclusions, and generic filler.
- Keep one idea per paragraph where practical.

## Review before delivery

Ask whether a reader could quote the passage without losing the subject, qualification, timeframe, or evidence boundary. If not, revise the surrounding context rather than adding unsupported detail.
