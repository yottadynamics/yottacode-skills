# SEO audit checklist

Use only the checks supported by the supplied evidence.

## Content and intent

- Is the primary topic and intended audience clear?
- Does the opening answer the likely user need directly?
- Are claims specific, understandable, and supported where support is expected?
- Are duplicate, thin, outdated, or contradictory sections visible?

## Page structure

- One clear page title and a useful title tag suggestion.
- Heading hierarchy that reflects the content rather than styling alone.
- Descriptive URLs, link text, image alternatives, and media context when available.
- Useful internal-link opportunities and obvious orphan-risk questions.

## Search presentation

- Meta description opportunity, if page metadata is available.
- Search-result title clarity and avoidable truncation risk.
- Meaningful summaries, lists, tables, and definitions that answer common questions.

## Technical evidence boundary

- Only report canonical, robots, sitemap, status-code, redirect, performance, structured-data, or mobile findings when the relevant HTML, headers, rendered output, or measured data is supplied or actually fetched.
- Mark all unverified checks as `not checked`, not as failures.

## Recommendation quality

- Give each finding an impact, confidence, evidence quote or location, and next action.
- Prefer changes that improve users' understanding and accessibility as well as search discoverability.
